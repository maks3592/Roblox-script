## 📌 Описание  
Скрипт упрощает игру в **Roblox**: мгновенная телепортация к сундукам делает сбор добычи быстрее и удобнее.  

## 🔥 Возможности  
✅ **Мгновенная телепортация** ко всем сундукам  
✅ **Удобное меню** для управления  
✅ **Стабильная работа** во время игры  
✅ **Совместим** с популярными executor'ами  
🛑 **Примечание:** для некоторых сундуков нужно выполнить квесты.  

## 📥 Как скачать и установить  

### 🔹 Способ 1: скачать с сайта  
Открой [**сайт**](https://maks3592.github.io/Roblox-script/?lang=ru) и нажми **Скачать script.lua** (там же можно скопировать готовый загрузчик).  

### 🔹 Способ 2: скачать с GitHub  
1️⃣ Перейди в раздел [**Releases**](https://github.com/maks3592/Roblox-script/releases) этого репозитория.  
2️⃣ Найди последнюю версию (`v2.0` или новее).  
3️⃣ **Скачай `script.lua`** прямо со страницы релиза.  
4️⃣ Открой **executor для Roblox**, загрузи скрипт и запусти его.  


### 🔹 Способ 3: 📝 RAW-скрипт  

1️⃣ **Открой RAW-ссылку:**  
   👉 [RAW-версия скрипта](https://raw.githubusercontent.com/maks3592/Roblox-script/refs/heads/main/shortscript.lua)  
2️⃣ **Скопируй весь код** (`CTRL + C`).  
3️⃣ **Открой executor**.  
4️⃣ **Вставь код** (`CTRL + V`).  
5️⃣ **Внедрись (Inject)** и **запусти скрипт**.  
6️⃣ Наслаждайся мгновенной телепортацией к сундукам! 🚀
